# Verification

BLOGSITE는 Next.js + TypeScript 프로젝트입니다. 사용자는 개발 지식이 없어 코드가
제대로 동작하는지 직접 확인할 수 없으므로, 중요한 코드를 수정할 때마다 이 스킬로
직접 검증하고 결과를 한국어로 알기 쉽게 보고해야 합니다.

## 실행 방법

저장소 루트에서 아래 명령을 실행합니다.

```bash
bash .claude/skills/verification/check.sh
```

스크립트는 다음을 순서대로 수행합니다.
1. `node_modules`가 없으면 `npm install` 자동 실행
2. `npx tsc --noEmit`으로 타입 에러 검사
3. `npm run build`(`next build`)로 빌드 검증
4. 마지막에 `타입 체크: PASS/FAIL`, `빌드 체크: PASS/FAIL` 요약 출력

타입 체크나 빌드 중 하나라도 실패하면 스크립트는 종료 코드 1을 반환합니다.

## 언제 실행해야 하는가

- 컴포넌트, 페이지, API 라우트, lib 등 실제 동작에 영향을 주는 코드를 수정/추가/삭제한 직후
- 여러 파일에 걸친 수정이 끝난 뒤, 커밋하거나 푸시하기 전
- 사용자가 "확인해줘", "제대로 되는지 봐줘" 등으로 요청했을 때

문서(.md)나 주석만 수정한 경우처럼 코드 동작에 영향이 없는 변경에는 실행하지
않아도 됩니다.

## 결과 보고 방법 (사용자는 비개발자)

- PASS면 "타입 에러와 빌드 문제 없이 정상 확인됐어요" 정도로 짧게 알린다.
- FAIL이면 원본 에러 로그를 그대로 붙여넣지 말고, 다음을 포함해 쉬운 말로 요약한다.
  - 어떤 파일(`file:line`)에서 문제가 발생했는지
  - 무엇이 문제인지 한두 문장으로 (전문 용어 최소화)
  - 가능하면 바로 고쳐서 재검증까지 진행하고, 고친 뒤에는 다시 이 스킬을 실행해
    통과했는지 확인한다.
- 로그 전체가 필요할 때만(예: 사용자가 자세히 보고 싶어할 때) 원문을 보여준다.
